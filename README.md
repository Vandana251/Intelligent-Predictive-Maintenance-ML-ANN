# Intelligent Predictive Maintenance & Machine Failure Risk Management

Author: Vandana Illipilla

## Dataset
AI4I 2020 Predictive Maintenance Dataset, UCI Machine Learning Repository (10,000 rows, 14 columns).
Source: https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset
The file used is `ai4i2020.csv`. Place it next to the notebook, in the project root or in `/content` (Google Colab).

## How to run
1. Create an environment and install the packages: `pip install -r requirements.txt`
2. Open `notebooks/Predictive_Maintenance.ipynb` and run all cells from top to bottom.
3. The notebook writes `results/` (CSV tables), `figures/` (plots) and `reports/Final_Technical_Report.pdf`.

## Folder structure
- notebooks/Predictive_Maintenance.ipynb : executable notebook with explanations and outputs
- reports/Final_Technical_Report.pdf      : technical report generated by the notebook
- results/model_comparison.csv            : test metrics and settings of the three models
- results/experiment_results.csv          : controlled ANN experiment with settings and seeds
- README.md, requirements.txt

## Assumptions and notes
- TWF, HDF, PWF, OSF, RNF, UDI and Product ID are not used as model inputs (leakage safeguard).
- Preprocessing is fitted on the training split only. Split: 70% train, 15% validation, 15% test, stratified, seed 42.
- The inspection cost (100 units) and missed-failure cost (1000 units) are hypothetical, not real factory costs.
- Risk bands and thresholds are illustrative and must be re-checked with real costs and maintenance experts.
- The dataset is synthetic and is not a per-machine time series. Scores can differ slightly between library versions.
- No external model code was copied; all code uses the documented APIs of pandas, scikit-learn, TensorFlow/Keras, SciPy and ReportLab.
